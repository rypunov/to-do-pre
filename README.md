# 📝 To-do List

Приложение для управления списком дел с сохранением в локальное хранилище.

## 🚀 Функционал

- Просмотр списка задач
- Добавление новых задач
- Удаление задач
- Копирование задач
- Редактирование текста задач
- Сохранение задач после перезагрузки страницы

## 🛠 Технологии

- JavaScript
- LocalStorage
- HTML и CSS (были предоставлены готовыми)

## 📦 Установка и запуск

1. Склонируйте репозиторий
2. Откройте файл `index.html` в браузере

## 💡 Как пользоваться

- **Добавить задачу** — введите текст и нажмите Enter или кнопку «Добавить»
- **Удалить задачу** — нажмите на кнопку с крестиком
- **Копировать задачу** — нажмите на кнопку копирования
- **Редактировать задачу** — нажмите на кнопку с карандашом, измените текст и кликните вне поля

## 💾 Сохранение данных

Все задачи автоматически сохраняются в `localStorage`. При перезагрузке страницы список задач восстанавливается.
